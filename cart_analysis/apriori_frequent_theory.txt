association rules
itemsets = subset of items in a cart; each record/orderID in Vori is composed of a set of items; an itemset is a subset of these. A particular subset may occur frequently in many carts; an itemset can be of any length - even 1
market based analysis

apriori algorithm 
- support = the proportion of carts/orderIDs that contain the itemset
- confidence = P(X|Y) - the probability of seeing X given that we see Y
- lift (ostensibly a test for independence) = (support of X&Y) / [support(X) * support(Y)] ... if this eq > 1 then we can say there is a dependence between the two values (x and y)

Several algorithms have been developed to address Apriori’s limitations. The FP-Growth algorithm uses a compact tree structure to avoid multiple database scans, making it significantly faster for large datasets. ECLAT employs a depth-first search strategy using transaction ID sets. More recent developments include algorithms for mining sequential patterns, multi-level associations, and rare itemsets.
